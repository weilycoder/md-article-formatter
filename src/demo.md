# 欢迎使用 Markdown 格式化工具
这是一个**示例**文本。


请在此输入您的 Markdown 内容，或点击下方**上传**按钮导入 .md 文件。


## 基础功能

规范化不影响渲染的 markdown 格式问题。

## 可选选项

您可以选择性地启用或禁用以下功能，并在右侧预览中查看效果。

### 中英文空格（包含数字）

你好World

### 中文与行内公式空格

质能方程$E=mc^2$

### 中文与行内代码空格

Python 交换语句`a, b = b, a`

### 英文标点替换

你好,世界

### 代码格式化（Beta，默认不开启）

```cpp
#include<iostream>
using namespace std;
int main() {
  int a,b;
  cin>>a>>b;
  cout << a+b << endl;
return 0;
}
```
